# S3

提供兼容 S3 协议的对象存储管理和文件上传能力

- 支持维护多个 S3 存储配置
- 支持按指定存储配置上传文件
- 适用于 MinIO、AWS S3 或其他兼容 S3 协议的服务

## 插件类型

- 应用级插件

## 配置说明

当前插件无需额外配置

## 使用方式

1. 安装并启用插件后，重启后端服务
2. 创建 S3 存储配置
3. 上传文件时指定目标存储配置 ID

## 卸载说明

- 卸载插件后，建议清理业务中保存的 S3 存储配置和文件引用
- 远端对象存储中的文件需按业务策略手动处理
