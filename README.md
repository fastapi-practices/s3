# S3

提供兼容 S3 协议的对象存储配置与文件读写能力

- 支持维护多个 S3 存储配置，并可指定默认存储
- 支持按指定存储配置上传文件
- 供其它插件按对象键读写文件
- 适用于 MinIO、AWS S3 或其他兼容 S3 协议的服务

## 插件类型

- 应用级插件

## 配置说明

插件目录下 `plugin.toml` 的 `[settings]` 中包含以下内容：

```toml
[settings]
S3_UPLOAD_SIZE_MAX = 20971520
```

当前项目的 `backend/core/conf.py` 已包含以下字段：

```python
##################################################
# [ Plugin ] s3
##################################################
# 基础配置（in plugin.toml）
S3_UPLOAD_SIZE_MAX: int = 20 * 1024 * 1024
```

## 配置项说明

- `S3_UPLOAD_SIZE_MAX`：控制后台上传文件的最大字节数

## 使用方式

1. 安装并启用插件后重启后端服务
2. 在后台维护 S3 存储配置，并指定一个默认存储
3. 其它插件通过默认存储或指定存储 ID 按对象键读写文件

## 卸载说明

- 卸载插件后，建议同步移除插件基础配置和 `backend/core/conf.py` 中的插件配置
- 建议清理业务中保存的 S3 存储配置和文件引用
- 远端对象存储中的文件需按业务策略手动处理
